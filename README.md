# my-portfolio

Personal portfolio site built with React, Vite, Tailwind CSS and Framer Motion.
Live at https://malakblm.github.io/my-portfolio/

## Run locally

    npm install
    npm run dev

## Edit content

Almost everything you will want to change (skills, experience, projects, email) lives in `src/data.js`.

## Publish to GitHub Pages

    npm run deploy

This builds the site and pushes the result to the `gh-pages` branch, which GitHub Pages serves.
The source code lives on the `main` branch.
